# تطبيق الخيار A: تحسين شبكة الماء الخارجية

تم تنفيذ التعديل عبر Unity MCP في GameScene، دون تعديل CurvedWorldView أو الشيدر أو قيم الانحناء أو الضباب أو الكاميرا.

- الأصل المعدّل: `Assets/ProjectsFiles/Rendering/CurvedWorld/CurvedWaterHorizon.asset`، مع الاحتفاظ بنفس GUID والمراجع.
- الحجم باقٍ `312.5 × 312.5` والارتفاع `0.2`.
- القيم الحالية محفوظة كما كانت: IsActive=true، BendStrength=0.015، BendStartDistance=15.
- قُسمت أضلاع المثلثات الخارجية الأطول من 8 وحدات عالمية تقسيمًا متوافقًا بين المثلثات المتجاورة. لا تشققات داخلية ولا وجوه مقلوبة أو متدهورة وفق فحص الطوبولوجيا.
- أول 121 رأسًا وUV، وأول 200 مثلث للشبكة المركزية، بقيت كما هي. الـCollider بقي 121 رأسًا.
- UV الجديدة هي استيفاء خطي للخريطة الأصلية؛ أقصى اختلاف عن الخريطة affine نحو `0.0000011`، دون تغيير إعدادات الماتيريال أو الأمواج أو الرغوة.
- حفظت حدود Mesh الأصلية بما فيها هامش الأمواج؛ حدود Renderer بقيت موسعة للأسفل لاستيعاب هبوط الانحناء. لم تزد مساحة سطح الماء.

## التحقق المنفذ

انظر `validation.txt` للنتائج الرقمية و`refine-water.cs.txt` لكود العملية داخل المحرر. لا يضاف أي سلوك أو مولّد شبكة إلى اللعبة.

|---|---:|---:|
| الرؤوس | 177 | 12485 |
| المثلثات | 344 | 24712 |
| أقصى خطأ ارتفاع عند مراكز المثلثات، موضع (68.75,4.3,6.76) | 5.5045 | 0.1057 |
| أقصى خطأ ارتفاع عند مراكز المثلثات، موضع (75.67,2.77,10.41) | 5.9161 | 0.1015 |

هذه أخطاء مقاسة عند مراكز المثلثات للدالة الحالية دون الأمواج، وليست حدًا رياضيًا مضمونًا لكل نقطة أو موضع كاميرا.

قارنت لقطتي الجزيرة والبحر من الموضع الأول، pitch=2، yaw=270/90، باستخدام Main Camera. لقطة before بدقة 640×360، وafter بدقة 960×540، بنفس نسبة الأبعاد وFOV=60. أضيفت لقطتا شرق وشمال من موضع الشاطئ الثاني. ظهرت الحافة أكثر سلاسة وبقي شكل الجزيرة والجسور المنحني؛ الصور التقطت في Edit Mode وليست اختبار مباراة. الوقت مختلف بين الصور، لذا لا تُستخدم لمقارنة طور حركة الأمواج بكسلًا ببكسل.

أعيدت الكاميرا بعد الالتقاط إلى Transform السابق، وحُفظ أصل Mesh وGameScene، وتأكد عدم وجود حالة dirty بعد الحفظ. لم تُغيّر إعدادات الشيدر أو الماتيريال أو الفيزياء أو التصويب أو الشبكة.

الزيادة 12308 رؤوس و24368 مثلثًا، مع Renderer واحد وSubmesh واحد كما كانا، ودون مواد أو passes أو كاميرات إضافية. لا توجد إعادة بناء للشبكة وقت التشغيل. زيادة الهندسة تزيد عمل GPU؛ لم ينفذ قياس CPU/GPU أو draw calls معزول، ولا يُستنتج ضمان أداء من هذا التحقق.
