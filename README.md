# TankProject 

**TankProject** is a simple, competitive 2v2 online multiplayer tank game built using **Unity 6**. The game focuses on strategic team cooperation to defend your base while actively pushing to destroy the enemy's stronghold.

##  Core Gameplay
The match revolves around a 2v2 team combat system with a primary objective. Each team protects a main Base. As long as the base is intact, players will continuously respawn after being destroyed. Once a team's base is destroyed, they lose the ability to respawn, turning the match into a high-stakes sudden death.

###  Win Condition
1. **Phase One:** Breach enemy defenses and destroy the Enemy Base.
2. **Phase Two:** Eliminate the remaining enemy tanks to secure the victory.

##  Game Mechanics
* **Players:** 4 players total (2 teams of 2).
* **Respawn System:**
  * **Base Active:** Killed players respawn at their base after a short cooldown timer.
  * **Base Destroyed:** Respawning is disabled; death becomes permanent for the round.
* **Environment:** A closed arena map featuring obstacles and barriers for cover and tactical positioning.
